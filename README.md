# esp-libsupla
libsupla ESP IDF Component

## compatibility

- [ESP8266 RTOS-SDK](https://github.com/espressif/ESP8266_RTOS_SDK)
- [ESP-IDF](https://github.com/espressif/ESP-IDF)

## How to start

To use this component in your project go to `components` directory and run:

`git clone --recursive https://github.com/QB4-dev/esp-libsupla`



## Installation

### Using ESP Component Registry

[![Component Registry](https://components.espressif.com/components/qb4-dev/esp-libsupla/badge.svg)](https://components.espressif.com/components/qb4-dev/esp-libsupla)

```bash
idf.py add-dependency "qb4-dev/esp-libsupla=*"
```

### Manual Installation

Clone this repository into your project's `components` directory:

```bash
cd your_project/components
git clone --recursive https://github.com/QB4-dev/esp-libsupla
```
